🔧 如何添加自定义工具

在 step3_agent_core.py 中三步即可添加新工具：

1. 定义工具函数（必须 @tool + 类型注解 + docstring）：

@tool
def my_new_tool(param1: str, param2: int) -> str:
    """工具描述（LLM 依据此判断是否调用）"""
    return f"结果: {param1} {param2}"

2. 注册到 TOOLS 列表：

TOOLS = [get_weather, calculator, get_current_time, web_search, my_new_tool]

3. 重启助手，LLM 会自动识别新工具。

规范：必须 @tool | 完整类型注解 | 清晰 docstring | 返回 str | 自行处理异常
